# 🏰 侠盗猎马人:中世纪王国
### Grand Theft Horse: Medieval Kingdom

一个**GTA 式开放世界 × 中世纪 × 任天堂玩法**的缝合怪浏览器 3D 游戏。
纯 Three.js 打造,零外部资源,开箱即玩。

![喷泉广场](docs/screenshot-plaza.png)

## 🎮 立即游玩

```bash
# 在仓库根目录启动任意静态服务器,例如:
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

无需安装依赖、无需构建——Three.js 已内置在 `lib/` 中,完全离线可玩。

## 🕹️ 操作

| 按键 | 动作 |
|---|---|
| `W A S D` | 移动 |
| `Shift` | 疾跑 / 策马狂奔 |
| `空格` | 跳跃(支持二段跳;骑马也能跳) |
| `E` | 骑马 / 偷马 / 与委托人对话 / 开宝箱 / 下马 |
| `F` 或 `鼠标左键` | 挥剑 |
| `M` | 开关背景音乐 |
| 鼠标 | 转动视角(点击画面锁定指针) |

## 📜 玩法指南

1. **接任务**:去喷泉广场找头顶金色"!"的老者,依次完成三个委托:
   - ① 金币税 — 收集 8 枚金币
   - ② 皇家快递 — 60 秒内骑马把包裹送到风车磨坊
   - ③ 剿灭盗贼 — 扫平西部森林的盗贼营地
2. **犯罪与通缉**:偷有主的马、袭击村民或卫兵都会升起 ⭐ 通缉星。星级越高,追兵越多越快(3 星起出动红衣皇家骑士)。躲开卫兵视线一段时间即可洗白;被打倒会没收一半金币。
3. **任天堂式小技巧**:跳到卫兵/盗贼**头上**能把他踩晕;从下方顶 **? 砖块**爆金币;野外散落着 6 个宝箱,补心又给钱。
4. 完成全部委托后,回广场领取 **★ 力量之星 ★** 通关——世界仍然开放,继续撒欢。

## 🔧 技术说明

- **引擎**:Three.js r160(已 vendored 到 `lib/`,无 CDN 依赖)
- **美术**:全部几何体程序化生成的低多边形卡通风格,无任何贴图/模型文件
- **音频**:WebAudio 实时合成的 8-bit 音效与中世纪小调 BGM,无音频文件
- **系统**:昼夜循环(太阳/月亮/星空/火把)、简单物理(重力跳跃 + 圆/盒碰撞)、
  状态机 AI(卫兵巡逻→追捕→攻击、村民游荡→逃跑、马匹吃草)、任务状态机、Canvas 小地图

```
├── index.html        # 入口 + HUD + 标题画面
├── lib/three.module.js
└── src/
    ├── main.js       # 主循环、玩家、通缉、任务、HUD、小地图、昼夜
    ├── world.js      # 世界搭建:城堡、城墙、村庄、森林、风车…
    ├── entities.js   # 人形/马匹模型构建器 + 碰撞
    └── audio.js      # WebAudio 芯片音乐合成器
```
